请帮我开发一个私人照片展示网站。
项目定位：这是一个“个人摄影档案馆”风格的网站，而不是传统情侣告白网站。核心目标是：让照片成为绝对主角，网站本身像一个高级摄影作品展示平台。
设计风格：
 极简
 高级
 留白充足
 类似 Apple 官网、摄影师作品集、日系旅行记录网站
 不使用大量情感文字
 不使用夸张爱心、粉色浪漫元素
 不做营销风格
视觉要求：
 白色或浅灰背景
 黑灰色文字
 简洁排版
 大尺寸图片展示
 图片有轻微悬停放大效果
 页面动画自然、克制
 注重浏览照片时的沉浸感
首页设计：
1. 顶部导航：简洁透明导航栏。
左侧：OUR GALLERY
右侧：首页相册旅行时间轴
移动端：转换为汉堡菜单。
2. Hero区域：首页第一屏使用一张大尺寸照片作为视觉中心。
要求：
 图片占据主要空间
 圆角设计
 图片覆盖显示
 底部只显示简单信息：
地点日期
例如：
Tokyo2025.03
不要出现：“遇见你是最美的意外”“我们的爱情故事”等大量文字。
3. Moments 时间区域：
使用简洁列表展示照片记录：
例如：
Japan
Tokyo · 2025.03
36 Photos
Summer
Shanghai · 2024.08
52 Photos
重点展示：地点时间照片数量
4. Latest 图片墙：
使用响应式 Masonry/Grid 布局。
要求：
桌面：4列图片墙
手机：2列图片墙
图片效果：
 圆角
 hover轻微放大
 点击后可以进入大图查看
5. Albums相册区域：
展示分类：
JapanDailyTravel
卡片设计：白色卡片圆角轻阴影
不要复杂装饰。
技术要求：
前端：Vue3 + Vite + TypeScript
样式：Tailwind CSS
动画：GSAP 或 Framer Motion
要求组件化开发：
components:
 Navbar
 HeroImage
 PhotoGrid
 AlbumCard
 TimelineItem
 PhotoViewer
代码要求：
 保持代码结构清晰
 不写大量重复 HTML
 数据与页面分离
 图片路径使用变量管理
 为后续接入 Flask API 做准备
响应式要求：必须兼容：
手机：375px宽度
平板：768px
电脑：1440px
移动端优先设计。
未来扩展：后续会增加：
 Flask 后端 API
 MySQL 图片数据管理
 用户登录
 图片上传
 图片分类
 Nginx 部署
所以前端设计需要方便后续扩展。
最终目标：生成一个看起来像专业摄影网站的私人照片展示平台。

6. 图片展示效果
